# NEON STACK · 霓虹堆栈

## 游戏目标
一个可以立即游玩的中文赛博朋克俄罗斯方块小游戏。玩家旋转、移动七种方块，填满横行消除并获得分数；每消除十行提升等级、加快下落，堆至顶部时结算，支持再次挑战。

## 视觉与布局
雨夜未来都市作为全屏环境，深靛蓝背景、青色主强调、玫红奖励色。细线框、终端编号、切角按钮与克制的扫描纹理构成界面。中心 10×20 棋盘始终最清晰，左右分别显示分数/等级/暂存与下一个队列。中文说明配合英文标题、等宽数值。窄屏收拢为顶部状态条、棋盘与右侧预览、底部触控。

## 核心系统
- 七袋随机，标准七种四格方块，顺/逆时针旋转，墙踢，约 450ms 落地延迟。
- 落点幽灵，硬降与软降，暂存每个活动方块仅一次；三个后续方块可见。
- 单/双/三/四行按 100/300/500/800 × 当前等级计分，连续消行奖励；软降 1 分/格，硬降 2 分/格。
- 每十行升级，渐进加速；顶部堵塞时结束，保存最佳成绩。
- 开始、暂停、继续、结束重开、帮助、音乐/音效开关；离开窗口自动暂停。
- 输入：←→ 移动，↑/X 顺转，Z 逆转，↓ 软降，空格硬降，C/Shift 暂存，P/Esc 暂停。触屏按钮与棋盘手势可用。
- Web Audio 合成反馈与低音量合成器节拍；声音仅在用户交互后启动。
- OhMyGame game.storage 保存最高分；失败时显示保存状态，不阻止游戏。

## 技术与完成标准
Vite + 原生 JavaScript + Canvas 2D；小规模网格游戏无需完整引擎。棋盘逻辑与渲染分离。静态构建到 dist，资源采用相对 URL。实际试玩覆盖开始、移动、旋转、硬降、暂存、暂停/恢复、结束/重开和桌面/手机布局，并验证消行与升级逻辑。
